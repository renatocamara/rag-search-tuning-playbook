# Contoso Water Solutions dataset

Everything here is generated by `scripts/data/generate_contoso_data.py`. Edit the generator, not the files.

| Folder | Loaded into | Content |
|---|---|---|
| `catalog/parts.json` | Cosmos DB `parts` | 26 items: 15 products, 11 service parts (status, price, kit, replacements) |
| `catalog/cross_reference.json` | Cosmos DB `crossReference` | 9 competitor equivalents (Litware, Tailspin, Woodgrove) |
| `docs/current/` | Blob `contoso-docs/current/` | 20 official documents |
| `docs/archive/` | Blob `contoso-docs/archive/` | 5 superseded documents (stale-content traps) |
| `docs/community/` | Blob `contoso-docs/community/` | 3 forum threads (two with wrong advice) |
| `eval/eval_set.jsonl` | `scripts/eval/run_eval.py` | 35 questions with expected part numbers, documents and answers |

Deliberate traps, so each module has something to fix:

* Look-alike part numbers: `CF-1100-XL`, `CF-1100-XLS`, `CF-1101-XL`; `ND-415-A`, `ND-415-AS`, `ND-415-AR`, `ND-515-A`.
* Superseded repair kit `K-CF-1100-RK` (archive and community say to use it; current says `K-CF-1100-RK2`).
* Archived `CF-1100-XL` sheet with a different price ($368 vs $412) and the old kit.
* 2021 warranty policy with shorter terms than the 2026 one.
* 2020 install guide with a different minimum pressure (20 psi vs 25 psi).
* Community thread recommending a 6 month filter interval (official: 3,000 gallons or 12 months).
* Every spec sheet has prose first and the table last, so fixed-size chunking separates the table from the part number.
