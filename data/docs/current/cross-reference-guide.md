# Competitor cross reference guide

Use this guide to find the Contoso Water Solutions equivalent of a competitor part. Equivalents are functional matches, not drop-in replacements for service parts: repair kits, filters and strainers are never interchangeable across manufacturers.

| Competitor | Competitor part | Description | Contoso equivalent | Match type |
|---|---|---|---|---|
| Litware | L-9450 | Manual flush valve 1.28 gpf, 1 in inlet | CF-1100-XL | Functional equivalent |
| Litware | L-9450-S | Sensor flush valve 1.28 gpf | CF-1100-XLS | Functional equivalent |
| Litware | L-9460 | Manual flush valve 1.6 gpf | CF-1100-XL | Nearest current equivalent |
| Tailspin | TS-BF200 | Bottle filling station, non-refrigerated | FX-2200-B | Functional equivalent |
| Tailspin | TS-BF200R | Bottle filling station, refrigerated | FX-2200-BR | Functional equivalent |
| Woodgrove | WG-FD4 | 4 in round floor drain, nickel bronze top | ND-415-A | Functional equivalent |
| Woodgrove | WG-FD4-SB | 4 in round floor drain with sediment bucket | ND-415-AS | Functional equivalent |
| Woodgrove | WG-CO6 | 6 in round floor cleanout | ND-600-CO | Functional equivalent |
| Litware | LF-500 | Sensor lavatory faucet, hardwired | CF-1250-S | Functional equivalent |

## Notes

* Litware L-9460 (1.6 gpf) has no current 1.6 gpf Contoso equivalent. CF-1101-XL was discontinued in 2024; recommend CF-1100-XL.
* Woodgrove floor drain strainers use a different bolt pattern. ND-415-AR fits only Contoso bodies.
* Tailspin filters do not fit HydroFill stations.
